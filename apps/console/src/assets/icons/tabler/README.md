# Terminal MCP curated Tabler icon set

Selected SVG assets from Tabler Icons 3.48.0 (MIT). The full Tabler package is not a Terminal MCP dependency.

Canonical choices:
- Bottom nav Fleet: server-2.svg
- Bottom nav Slots: square-key.svg
- Bottom nav Connections: plug-connected.svg
- Bottom nav Settings: settings.svg
- Server: server.svg
- Mesh: topology-ring-3.svg
- Agents: users.svg
- Tasks: list-check.svg
- Activity: activity.svg
- Context: braces.svg
- Health: heart-rate-monitor.svg
- Copy: copy.svg
- Back: arrow-left.svg
- Disclosure chevron: chevron-right.svg
- Horizontal overflow: dots.svg
- Navigation drawer: menu-2.svg

Alternatives are included for topology, infrastructure, actions, status, activity, access and connectivity so new UI work should normally not need another icon family.

Rules:
1. Prefer the canonical choices above for shared product semantics.
2. Add another Tabler SVG only when the curated set has no suitable semantic icon.
3. Keep original 24x24 Tabler geometry and outline style.
4. Decorative icons are aria-hidden; interactive controls retain accessible labels.
5. Keep LICENSE.tabler.txt with redistributed icons.
