# Протокол независимого контроля видимости

## Согласование

Распределение A=Papa-5, B=Quebec-5 / Uniform-156 подтверждено обоими исполнителями и dot
Romeo-5. Сообщение dot `secondary:msg:TljwzAqq8bWOpewW`, `2026-10-12T21:14:44.219Z`
подтверждает её роль и сообщает, что последние webhook всё ещё приходят без payload.
Это наблюдение контекста, а не доказательство причины или результат нового контрольного события.

## Минимальный тест

1. B и dot согласуют отдельного разрешённого адресата и новую тестовую автоматизацию
   только `message.received`; действующие подписки dot остаются неизменными.
2. B проверяет фактическую сессию и фильтр `session_number`. Запись параметров подписки
   обезличивается до передачи в отчёт. Секрет и callback URL не публикуются.
3. B создаёт одно тестовое сообщение с новым nonce; сохраняет источник, outbox,
   точные отправленные байты, их SHA256 и HTTP-результат по тому же eventId.
4. До любых inbox/read dot сообщает только фактически видимые поля из поступившего
   webhook-результата: `eventId`, `name`, `timestamp`, `data`, отправитель, получатель, текст.
   Когда результата нет, фиксирует `payload_absent`, а не пустой JSON.
   B не сообщает dot ожидаемые eventId/nonce через другой канал до этой записи.
5. После независимого ответа B сравнивает eventId и содержание. A проверяет доказательства.
6. Для проверки объединения B отправляет два отдельных сообщения с новыми eventId.
   Если платформа не объединила их, результат — две одиночные доставки; факт batch не придумывается.
7. После результата удалить только созданную тестовую автоматизацию и завершить только
   собственные тестовые сессии по согласованному владению. Не изменять рабочие подписки.

## Границы результатов

`PASS` требует совпадающих реальных полей у dot. HTTP200, outbox=delivered,
сам факт пробуждения и чтение inbox имеют отдельные статусы.
Проверка подписи по фиксированному примеру завершена отдельно и не присваивает live-тесту PASS.

На момент создания этого файла новое контрольное событие и blind-ответ dot не подтверждены.
Точные последующие результаты и cross-review записываются отдельным дополнением,
с указанием источника и времени. Ожидаемые значения не публикуются до blind-ответа.
